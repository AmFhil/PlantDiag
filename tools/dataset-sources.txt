DATASET 1: CASSAVA (5 classes)
================================================================================
Classes:
  - Cassava___Bacterial_Blight
  - Cassava___Brown_Streak_Disease
  - Cassava___Green_Mottle
  - Cassava___Mosaic_Disease
  - Cassava___Healthy

Source: Makerere AI Lab / iCassava 2019-2021 Kaggle Competition
URL   : https://www.kaggle.com/c/cassava-leaf-disease-classification
Images: 21,397 total (real field photos from Uganda/Tanzania/Nigeria)
Format: JPEG, ~800x600px, label_num_to_disease_map.json for class mapping
License: CC BY-SA 4.0

Class ID Map (from label_num_to_disease_map.json):
  0 = Cassava Bacterial Blight (CBB)     → Cassava___Bacterial_Blight
  1 = Cassava Brown Streak Disease (CBSD)→ Cassava___Brown_Streak_Disease
  2 = Cassava Green Mottle (CGM)         → Cassava___Green_Mottle
  3 = Cassava Mosaic Disease (CMD)       → Cassava___Mosaic_Disease
  4 = Healthy                            → Cassava___Healthy

Download (requires free Kaggle account):
  pip install kaggle
  kaggle competitions download -c cassava-leaf-disease-classification
  unzip cassava-leaf-disease-classification.zip -d datasets/cassava_raw/

Alternative (no login, via HuggingFace datasets library):
  pip install datasets
  python -c "
  from datasets import load_dataset
  ds = load_dataset('yt0609/cassava-leaf-disease-classification')
  ds.save_to_disk('./datasets/cassava_hf')
  "

Notes:
  - 80% train / 20% val split recommended (already shuffled in the CSV)
  - Images are in train_images/ folder; labels in train.csv
  - Use the remap script in tools/remap_cassava.py to rename into class folders

DATASET 2: MAIZE / CORN (4 classes)
================================================================================
Classes:
  - Corn_(maize)___Common_Rust
  - Corn_(maize)___Northern_Leaf_Blight
  - Corn_(maize)___Fall_Armyworm
  - Corn_(maize)___Healthy

Source A: Corn or Maize Leaf Disease Dataset (Kaggle)
URL     : https://www.kaggle.com/datasets/smaranjitghose/corn-or-maize-leaf-disease-dataset
Images  : ~4,100 images (Common Rust, Blight, Gray Leaf Spot, Healthy)
Format  : JPEG already organized into class folders

  kaggle datasets download -d smaranjitghose/corn-or-maize-leaf-disease-dataset

Source B: Fall Armyworm — Makerere Fall Armyworm Crop Challenge (Zindi/Kaggle)
URL     : https://www.kaggle.com/datasets/mrisdal/maize-fall-armyworm-dataset
OR      : https://zindi.africa/competitions/makerere-fall-armyworm-crop-challenge/data
Images  : ~2,000 damaged whorl and leaf images
Note    : Use only "damage" class images (not egg/pupa) for our FAW damage class.

  kaggle datasets download -d mrisdal/maize-fall-armyworm-dataset

Class Mapping:
  Common Rust        → Corn_(maize)___Common_Rust
  Northern Leaf Blight (Blight) → Corn_(maize)___Northern_Leaf_Blight
  Fall Armyworm damage images   → Corn_(maize)___Fall_Armyworm
  Healthy            → Corn_(maize)___Healthy
  (Exclude Gray Leaf Spot — not common in Nigeria)

          that released dataset on supplementary materials)

  https://universe.roboflow.com/search?q=yam+disease

DATASET 6: TOMATO (6 classes)
================================================================================
Classes:
  - Tomato___Bacterial_Spot
  - Tomato___Early_Blight
  - Tomato___Late_Blight
  - Tomato___Yellow_Leaf_Curl_Virus
  - Tomato___Leaf_Miner_Tuta
  - Tomato___Healthy

Source A: PlantDoc Dataset (real field images — key for domain adaptation!)
URL    : https://github.com/pratikkayal/PlantDoc-Dataset
OR     : https://public.roboflow.com/object-detection/plantdoc
Images : ~2,600 field images for tomato classes
License: MIT

  git clone https://github.com/pratikkayal/PlantDoc-Dataset
  (already has Bacterial Spot, Early Blight, Late Blight, Leaf Miner, Healthy)

Source B: PlantVillage (lab background — use ONLY as training supplement)
URL    : https://www.kaggle.com/datasets/emmarex/plantdisease
  kaggle datasets download -d emmarex/plantdisease
  (Use tomato classes only: Bacterial_spot, Early_blight, Late_blight,
   Yellow_Leaf_Curl_Virus, Tomato_healthy)

Source C: Tuta absoluta / Tomato Leaf Miner
URL    : https://www.kaggle.com/datasets/juancarlosventojin/tuta-absoluta-tomato-leaf-miner
  kaggle datasets download -d juancarlosventojin/tuta-absoluta-tomato-leaf-miner

IMPORTANT: Mix PlantDoc (70%) + PlantVillage (30%) for tomato to get
field-realistic training without losing variety. Albumentations augmentation
on the PlantVillage portion simulates field conditions.

TOTAL ESTIMATED DATASET SIZE
================================================================================
Raw download size    : ~4.5 GB (ZIP files)
Extracted image size : ~8–12 GB
After preprocessing  : ~3 GB (224x224 JPEG, 85% quality)
Final train/val split: ~80/20 per class

Minimum per-class requirement:
  - 300 images/class minimum (for INT8 calibration stability)
  - 500+ images/class recommended for good generalization
  - Classes with < 300 raw images use Albumentations heavy augmentation
    to synthesize additional variants (see tools/train_naija_staples.py)


================================================================================
HOW TO USE: RECOMMENDED WORKFLOW
================================================================================

OPTION 1 — GOOGLE COLAB (RECOMMENDED, FREE GPU)
  1. Open: tools/NaijaStaples30_Training.ipynb in Google Colab
  2. Click "Connect" (T4 GPU, free tier)
  3. Run all cells — datasets download automatically via kaggle + requests
  4. Training runs ~3–5 hours on T4 GPU
  5. Download: output/naijastables_mobilenetv3_int8.tflite (~5–7 MB)
  6. Copy to: Agrinovva mobile app/android/app/src/main/assets/model/

OPTION 2 — LOCAL TRAINING (requires Python 3.10 or 3.11 + NVIDIA GPU)
  NOTE: Your current Python 3.14 is NOT supported by TensorFlow.
  Install Python 3.11 alongside 3.14 using pyenv or the official installer.

  Step 1: Install Python 3.11
    winget install Python.Python.3.11

  Step 2: Create virtual environment
    py -3.11 -m venv naija_env
    naija_env\Scripts\activate

  Step 3: Install dependencies
    pip install tensorflow==2.15.0 albumentations==1.3.1 matplotlib scikit-learn kaggle

  Step 4: Set Kaggle credentials
    Create ~/.kaggle/kaggle.json with your API key from
    https://www.kaggle.com/settings/account → "Create New Token"
    Contents: {"username":"YOUR_USERNAME","key":"YOUR_KEY"}

  Step 5: Run dataset download script
    python tools/download_datasets.py

  Step 6: Run training
    python tools/train_naija_staples.py --dataset-dir ./datasets

OPTION 3 — KAGGLE NOTEBOOKS (FREE GPU, NO DOWNLOAD NEEDED)
  - Create a Kaggle notebook
  - Add all listed datasets as "Data Sources" (one-click, no download)
  - Paste training code from tools/train_naija_staples.py
  - Datasets are already mounted at /kaggle/input/
  - Free GPU: 30h/week (P100 16GB)
